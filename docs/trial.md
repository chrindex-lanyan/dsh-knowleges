# 本机安装和会话试用

> 适用 DSH Desktop 0.2.2-rc.3。试装包：`dsh-knowledge-library-0.2.1.tgz`。使用现有应用，不另开 Web 服务。

## 安装 / 升级

1. 如果已从压缩包装过旧版，在 DSH 左栏「插件」打开 `dsh-knowledge-library`，先卸载旧包。本地压缩包不走注册表的「更新」。卸载插件不会删除库；仅在需要完整回退点时，先正常退出 DSH，备份其宿主数据目录里的 `knowledge-library-preview` 子目录。独立导出只包含正式条目和保留历史，不是完整回退备份。
2. 在「插件 → 添加插件」选择本机 `dsh-knowledge-library-0.2.1.tgz` 的绝对路径，点击「安装 → 立即启用」。如果 DSH 提示重启，按提示重启后再检查；仅刷新页面不替代宿主重启。
3. 左栏应出现「资料库」，「设置 → 资料库」应出现配置。新版本保留宿主目录和库键；首次打开旧库时事务迁移 SQLite，保留正式条目、历史及原待审单条。迁移后旧插件可能无法打开新版库，不要把重新安装旧包当作数据回滚。

## 在会话中验证四项变化

1. 先确认试用工作区仅含合成资料。打开「设置 → 资料库 → 会话工具」，勾选试用确认并开启。这只在当前 DSH 进程生效；默认安装重启后需要重开，不用改配置。
2. 回到已绑定项目的会话，发送下一条消息，例如：「在这个工作区一次提交三条合成测试资料的草稿：历史保留、归档规则、SQLite 导出检查；不要改全局库。」Host 会把可用知识工具和规则注入模型上下文，助手可调用批量提案，不需要先打开或授权工作区读取。
3. 在「资料库 → 待审核」选择目标工作区，打开批量待审，核对每条差异后一次确认。确认前普通列表没有这些条目；确认后回到会话可不经读审批搜索它们，或批量获取最多 20 个 UUID。任何陈旧基准使整批不入库。
4. 测试全局时，先让会话仅查询全局，查看「全局读授权」并选择一次或当前会话。用工作区的已读测试资料申请提炼到全局；全局读授权不会自动通过这个写提案，必须在全局待审中另外批准。
5. 浏览旧版本、查看指标与按库导出。导出为独立 `.sqlite`，包含正式条目和保留历史，不含未审批草稿或私有来源。

## 安全限制与停止试用

- 新装默认只开放人工预览；设置中的合成资料试用开关会在同一个库开启会话工作区直读。关闭会立即拒绝新调用、清除全局读授权和已读凭据，正式条目和已存在的待审申请不删。
- 已认证浏览器与普通程序 API Peer 分离，但同账号的文件、终端、凭据和桌面自动化可能越过应用界面边界。在真实 SSH、Native/PTC 和通用工具隔离完成验证前，不用真实或敏感资料试用。
- SSH 工作区只有在 DSH 工作区和远端项目身份都核验通过时才能读取；不接受从会话参数或路径推断其他库。若当前会话未登记归属，请从已登记工作区打开会话后再试。
- 在线导出限 32 MiB，下载凭证为短期单次使用。不能撤回已下载的文件。若不想继续使用，在插件详情关闭或卸载。
