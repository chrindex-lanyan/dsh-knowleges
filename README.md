# DSH 资料库插件

在 DSH 中管理全局和工作区资料。正式条目存于 SQLite；编辑、整理和提炼先生成提案，人工确认后才应用。支持版本历史、按库设置、指标和独立 SQLite 导出。

- [需求规格](<docs/requirements.md>)：D1–D3 和首版验收。
- [技术设计](<docs/design.md>)：宿主接入、权限、关系模型及事务边界。
- [本机试用与部署限制](<docs/trial.md>)：如何安装、验证和卸载。

## 开发与构建

需要 Node.js 24+ 和 npm。

```sh
npm ci
npm test
npm run pack:trial
```

默认只开放人工预览。要从会话试用，在「设置 → 资料库」确认合成资料并开启会话工具。会话可直接读取本工作区、批量提交草稿，全局读和批量写仍分别授权。正式条目只有在资料库界面确认后才更新。真实或敏感数据请等宿主隔离验收后再接入。
